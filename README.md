# RTA – RollerCoin Task Assistant

RTA is a local assistant for managing RollerCoin offers and tasks.

## Project goals

- Scan RollerCoin Taskwall offers
- Compare rewards and offer durations
- Detect new, removed and changed offers
- Track game and app offer progress
- Manage survey statistics
- Store personal profile information locally
- Provide a local dashboard for offer management

## Architecture

- Opera GX browser extension
- Local Node.js bridge
- Local web-based dashboard
- Local data storage

## Current status

**Version 0.3 – Offer Manager**

The scanner and local dashboard have been tested successfully. Further development is currently paused.

## Project philosophy

RTA is designed as a local-first assistant. It does not automatically answer surveys, bypass CAPTCHAs or submit offers on behalf of the user.

## Roadmap

- Improve offer history
- Add a 15-minute Taskwall refresh cycle
- Expand personal profile management
- Improve offer evaluation and statistics

## Disclaimer

RTA is an independent community project and is not affiliated with RollerCoin.
